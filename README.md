### Project Description
[
**CatGPT** is an AI-powered cat interpretation system that tries to answer the questions every cat owner has but is too afraid to ask. 🐱

Upload a picture of your cat, choose what you want to know, select a language and talking style, and CatGPT gives you an entertaining AI-generated interpretation of your cat's mood, thoughts, personality, activity and possible demands.

Because apparently, we needed Artificial Intelligence to understand why a cat is staring at a wall for 20 minutes.]

### The Problem (that doesn't exist)
[Cats refuse to communicate with humans.

They stare at us.

They ignore us.

They suddenly run around the house at 3 AM.

They sit inside boxes that are clearly too small.

And sometimes they look at us as if they know something we don't.

The real problem?

**We don't know what they're thinking.** 😭

Unfortunately, this is not a problem that society urgently needs to solve.

But we decided to solve it anyway.]

### The Solution (that nobody asked for)
[
Introducing **CatGPT** — because asking your cat directly was apparently not an option.

The user uploads a cat photo and selects what they want to know:

- 😺 Cat's Mood
- 💭 What is the cat thinking?
- 🧠 Cat's Personality
- 🐈 What is the cat doing?
- 🍗 What does the cat want?
- 😹 Fun Cat Analysis

The user can also choose:

- 🇬🇧 English
- 🇮🇳 Manglish

And choose the CatGPT personality:

- 🤖 Normal
- 😂 Funny
- 😺 Friendly
- 🔥 Roast

CatGPT then uses AI image understanding to generate a playful interpretation of the cat.

The results are clearly presented as **AI estimates for entertainment**, not scientific facts.
]

### Implementation
For Software:
# Installation
[Clone the repository:

``bash
git clone https://github.com/Fanajiya202596/catgpt.git
cd catgpt]
Go into the project folder:

cd catgpt

Install dependencies:

npm install

Create a .env.local file and add the Gemini API key:

GEMINI_API_KEY=your_gemini_api_key

Important: The API key should never be committed to GitHub.


# Run
Start the Vercel development server:

vercel dev

Open the local URL shown by Vercel, usually:

http://localhost:3000

Upload a cat image and start the analysis.
